Task managment tool for small, fast moving teams such as
startups, agencies, and product or design teams.

## Live Preview

https://novi-frontend-website.vercel.app/

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Motion
- Lucide React

## Features

- Animated hero section
- Interactive feature cards

## Getting Started

### Prerequisites

- Node.js 20+
- pnpm

### Installation

Clone the repository:

```bash
git clone https://github.com/mukulrajbanshi123/novi-frontend-website.git

cd novi-frontend

pnpm install

pnpm dev
```

Open http://localhost:3000
